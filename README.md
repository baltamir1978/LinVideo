# LinVideo

Descarga vídeo en MP4 y audio en MP3 con la máxima calidad desde YouTube y más de mil webs, con buscador integrado y vista previa. Funciona sobre yt-dlp y ffmpeg.

Versión para Linux de [AppVideo](https://github.com/baltamir1978/AppVideo), la app de macOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Python 3 + GTK 4 + libadwaita, para **Debian 13 con GNOME**. Se instala con un paquete `.deb`.
